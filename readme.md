# Текстовая RPG: Проклятие древнего короля

Консольная текстовая игра в жанре dungeon crawler, разработанная на C++17. Игрок исследует подземелье, сражается с нежитью, собирает предметы и должен найти корону, чтобы выбраться на поверхность.

## Особенности
- Полностью текстовый интерфейс с русской локализацией.
- Пошаговая боевая система с возможностью бегства.
- Инвентарь, экипировка оружия, использование лечебных зелий.
- Сохранение и загрузка игры.
- Динамическая загрузка мира из внешних файлов (`rooms.txt`, `items.json`, `enemies.txt`).
- Кроссплатформенность (Windows, Linux).

## Требования
- Компилятор с поддержкой C++17 (MSVC 2022, GCC 11+, Clang 14+).

## Сборка и запуск (Visual Studio 2022)
1. Откройте папку с проектом в Visual Studio.
2. Убедитесь, что все `.cpp` и `.h` файлы добавлены в проект.
3. Установите стандарт C++17: `Свойства проекта → C/C++ → Язык → Стандарт C++: ISO C++17`.
4. Поместите папку `data` на уровень с `.vcxproj` (или настройте рабочую папку отладки на `$(ProjectDir)`).
5. Соберите решение и запустите.
